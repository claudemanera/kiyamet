# Kiyamet (Fabric 1.21.11)

Build: push this folder to a GitHub repository. The "Build Kiyamet" action runs automatically;
download `kiyamet-jar` from the action's page and put the jar in `.minecraft/mods` together with Fabric API.

The 10 power-stone textures are made during the build from your own Minecraft client's amethyst shard
(tools/recolor_stones.py), so no Mojang texture is stored in this repository.
